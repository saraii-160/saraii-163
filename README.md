# 🎮 Scratch

## 🌟 Experiencia

Trabajar con **Scratch** fue una experiencia que me permitió aprender los fundamentos de la programación de una manera sencilla, visual y creativa. A través de bloques de programación pude crear animaciones, personajes, escenarios e interacciones sin necesidad de escribir código tradicional.

## 📚 Conocimientos adquiridos

Durante esta experiencia aprendí sobre:

- 🧩 **Programación por bloques:** utilización de bloques para construir instrucciones.
- 🔄 **Secuencias:** organización de instrucciones para ejecutar acciones en un orden determinado.
- 🔁 **Bucles:** repetición de acciones de manera automática.
- ❓ **Condicionales:** creación de acciones dependiendo de determinadas situaciones.
- 🎭 **Sprites y escenarios:** creación y personalización de personajes y fondos.
- 🎵 **Sonidos y animaciones:** incorporación de elementos multimedia para mejorar los proyectos.
- 🧠 **Lógica de programación:** desarrollo del pensamiento lógico para resolver problemas.

## 💡 Lo que aprendí

Una de las principales enseñanzas fue comprender que un programa está formado por **instrucciones organizadas de manera lógica**. Scratch me ayudó a entender conceptos básicos de programación que posteriormente pueden aplicarse en lenguajes más avanzados.

También aprendí la importancia de **probar, detectar errores y realizar cambios** hasta conseguir que el proyecto funcione correctamente.

## 🚀 Conclusión

La experiencia con Scratch fortaleció mi creatividad y mi capacidad de razonamiento lógico. Además, me permitió tener un primer acercamiento a la programación de una forma práctica y dinámica.

Esta herramienta demostró que es posible aprender conceptos de programación mientras se crean proyectos **interactivos, creativos y divertidos**.
